Essential Commands

Master these foundational terminal commands across development and systems environments.

📂 1–10 Basic Navigation

Command Purpose
pwd Show current directory
ls List files and directories
cd Change directory
cd .. Move back one directory
clear Clear terminal screen
whoami Show current user
uname -a Show system information
history Show command history
man ls Display manual of command
echo "text" Print text to terminal

📄 11–20 File Operations

Command Purpose
touch file.txt Create an empty file
mkdir folder Create a new directory
rm file.txt Remove (delete) a file
rm -r folder Remove a directory and all files
cp file1 file2 Copy file1 to file2
mv file folder/ Move file to folder
cat file.txt Display file content
nano file.txt Edit file using nano editor
head file.txt Show first lines of file
tail file.txt Show last lines of file

🔐 21–30 Permissions & Users

Command Purpose
chmod 777 file Change file permissions
chown user file Change file owner
id Show user ID information
groups Show user groups
adduser name Add a new user
passwd Change user password
sudo command Execute command as admin
su Switch to another user
userdel name Delete a user
who Show logged-in users

⚙️ 31–40 Process & System

Command Purpose
ps Show running processes
top Real-time process monitor
kill PID Kill a process by PID
df -h Show disk space usage
du -sh Show size of directory
free -m Show memory usage
uptime Show system uptime
vmstat Virtual memory statistics
iostat CPU and I/O statistics
dmesg Show kernel boot messages

🌐 41–50 Networking & Advanced

Command Purpose
ping google.com Test connectivity to host
ifconfig Show network configuration
ip a Show IP address details
netstat -tulnp Show open ports and connections
curl url Transfer data from or to a server
wget url Download file from internet
scp file user@ip:/ Secure copy to remote server
ssh user@ip Secure login to remote server
hostname Show or set system hostname
nslookup domain Lookup DNS information

🐙 Git

Command Purpose
git init Initialize repository
git add . Stage files
git commit -m "" Commit
git push Push code

🐳 Docker

Command Purpose
docker build -t app . Build image
docker run -p 3000:3000 app Run container
docker ps Running containers
docker images Images
